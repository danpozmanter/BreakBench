Correctness and memory safety

What happens when your program has a bug

Each problem is an ordinary program with one classic bug. A language can refuse to compile it, stop it with a clear error, or let it run on to a wrong answer, a crash, a hang or a leak.

Ranking

The score is the average over the problems a language can write, out of 100. The correctness and memory columns break it down; they are not separate rankings.

How outcomes are scored

A warning that names the bug adds 0.25, but never makes a full point. Ignoring a result the language marks must-use counts as a refusal.

A compile error counts as a refusal only if the same program with the bug removed compiles.

N/A means the language cannot write the program at all, for example without a mutex or shared-memory threads. Those problems leave its score. A language that simply lacks the bug, like Python with no unsigned integers, scores Ran Correctly.

Built-in safety

What safety comes built in?

Each probe asks whether the language itself prevents a common mistake: the compiler refuses the unsafe version, or the language gives you a safe construct such as a tagged union, a value type or a cleanup block. A probe that asks the compiler to refuse something passes only if the compiler refuses the marked line.

Ranking

Languages are ranked by how many probes they cover. Compiler-checked probes need a compiler that refuses unsafe code, so dynamic languages cannot pass them; language-feature probes need a construct in the language itself.

Library coverage

Which safe tools ship with the language?

Each probe asks whether the language ships a tool for a common mistake, such as a mutex, a JSON parser or password hashing. It counts if the standard library or a library the language's own project publishes provides it, plus ISO C and POSIX for C and C++. Some languages keep a small standard library on purpose and leave these tools to packages, so this is a profile of what ships, not a measure of how safe a language is.

Ranking

Languages are ranked by how many probes their own sources cover. The columns show where each covered probe comes from.
