BreakBench

What 30 programming languages do when a program has one classic bug. Can you trust the program to run without error in production, does the language help you find errors fast, and does it keep you from the big ones, like the billion-dollar null? A language can refuse to build the program, stop it with a clear error, or let it run on to a wrong answer, a crash, a hang or a leak.

Overview

The score is the average over all tests, as a percentage. The four categories break it down. Caught before running is the share of tests the compiler refused; no silent failure is the share refused, run correctly or stopped with a clear error. Select a heading to sort.

How outcomes are scored

A warning that names the bug adds 0.25, but never makes a full point. Ignoring a result the language marks must-use counts as a refusal.

A compile error counts as a refusal only if the same program with the bug removed compiles.

N/A means the language cannot write the program at all, for example without a mutex or shared-memory threads. Those tests score 0, the same as a failure. A language that simply lacks the bug, like Python with no unsigned integers, scores Ran Correctly.
